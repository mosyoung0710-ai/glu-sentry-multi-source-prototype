# 糖哨兵｜多种血糖源交互原型

这是糖哨兵“多种血糖源”功能的交互原型公开演示版。

## 在线预览

发布完成后，请点击 [GitHub Pages 演示页](https://mosyoung0710-ai.github.io/glu-sentry-multi-source-prototype/) 查看。

## 本版覆盖范围

- 糖糖圈 NS、其他 NS、糖糖圈账号、绑定 CGM 四类入口
- 已绑定血糖源的展示与修改入口
- 糖糖圈账号登录、血糖源选择与无可用血糖源提示
- 硅基动感授权 H5 示例

## 脱敏说明

本仓库仅包含静态演示页面，不连接真实服务。页面中的网址、密钥和其他示例数据均为演示内容，不包含患者信息、真实账号或真实接口地址。
