# 糖哨兵｜多种血糖源交互原型

这是糖哨兵“多种血糖源”功能的交互原型公开演示版。

## 在线预览

发布完成后，请点击 [GitHub Pages 演示页](https://mosyoung0710-ai.github.io/glu-sentry-multi-source-prototype/) 查看。

## 本版覆盖范围

- 糖糖圈 NS、其他 NS、糖糖圈账号、绑定 CGM 四类入口及选择指引
- 糖糖圈 NS 查询结果、其他 NS 绑定失败、糖糖圈账号登录提示与无可用血糖源状态
- 糖糖圈账号的密码登录、验证码登录及可用 CGM 选择
- 硅基动感授权页与已绑定血糖源的修改入口
- 在血糖源设置内切换 Tab 时保留未提交输入的交互示例

## 脱敏说明

本仓库仅包含静态演示页面，不连接真实服务。页面中的手机号、验证码、密码和密钥均为演示数据，不包含患者信息、真实账号或凭证。
